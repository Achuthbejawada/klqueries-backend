# 🧠 KL Queries – Student Query & Attendance Platform (Backend)

## 📌 Overview
**KL Queries** is a full-stack web platform that allows students to post academic queries, manage attendance, and receive real-time email notifications.  
This repository contains the **Spring Boot backend**, which powers authentication, query management, AI moderation, and Brevo-based email communication.

🔗 **Frontend Repository:** [KL Queries Frontend](https://github.com/Achuthbejawada/Kluqueries-frontend)  
🌐 **Live Website:** [https://klqueries.netlify.app](https://klqueries.netlify.app)

---

## 🚀 Features
- 🔒 **JWT Authentication** – Secure login and token-based access  
- 📨 **Email OTP Verification (Brevo API)** – Ensures secure account creation  
- 💬 **Query Management System** – Students can post, edit, delete, and reply to academic queries  
- 📩 **Email Notifications for Replies** – Automatically notifies users via email when someone replies to their query  
- 🤖 **AI Comment Moderation** – Detects and filters inappropriate or abusive language  
- 📅 **Attendance Tracking** – APIs to manage and display attendance data  
- ☁️ **Cloud Deployment** – Hosted on **Railway**, connected with PostgreSQL  
- 🔁 **CORS-enabled APIs** – Smooth connection with React frontend
